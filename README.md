## 📖 Overview | 專案概述

**MedCert AI** is not a generic text generator; it is a **Constraint-Based Assembly Pipeline**. It solves the most critical pain point in medical device submissions: the risk of AI hallucinations in regulatory documentation.

**MedCert AI** 並非通用的文本生成工具，而是一個 **「基於強約束的組裝管線」**。它解決了醫療設備提交中最核心的痛點：消除合規文檔中 AI 幻覺所帶來的監管風險。

### 💎 Value Proposition | 核心價值
| Feature | Business Value | 技術實作 |
| :--- | :--- | :--- |
| **Zero-Hallucination** | Eliminates regulatory risk and "fraud" flags from FDA. | 實作 `Verification Loop` 確保 100% 數據追溯。 |
| **Authority Narrative** | Transforms "Engineering Notes" $\rightarrow$ "Consultancy Grade Reports". | 內建 `Value Mining` 邏輯，將技術指標轉化為商業價值。 |
| **Rapid Prototyping** | Reduces drafting time from days to minutes. | 模塊化 `Constraint Library` 實現快速對標與填充。 |

## ⚙️ System Architecture | 系統架構

**The "Symmetry" Workflow $\longrightarrow$ 實作路徑**

`Fragmented Data` $\longrightarrow$ `Constraint Mapping` $\longrightarrow$ `Authority Synthesis` $\longrightarrow$ `Zero-Hallucination Check` $\longrightarrow$ `Certified Doc`
`碎片化數據` $\longrightarrow$ `約束對齊` $\longrightarrow$ `權威敘事合成` $\longrightarrow$ `零幻覺校驗` $\longrightarrow$ `認證文檔`

### 🛠 Core Modules | 核心模組
- **`src/constraints.json`**: The "Single Source of Truth" containing FDA 510(k) structural and linguistic constraints.
- **`src/mapping_engine.py`**: The brain that maps raw inputs to regulatory requirements.
- **`src/verifier.py`**: The "Police Agent" that cross-checks every single digit against the source data.

## 🛡️ Verification Protocol | 驗證協議

To ensure **Industrial Rigor**, this engine follows a strict internal audit:
- [x] **Numeric Traceability**: Every digit in the output must exist in the input.
- [x] **Linguistic Filtering**: Absolute ban on marketing superlatives (e.g., "Revolutionary").
- [x] **Structural Integrity**: Mandatory inclusion of Predicate K-numbers and ISO standards.
